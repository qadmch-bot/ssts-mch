إضافة زر إرسال تنبيه واتساب يدويًا إلى نظام Sepsis (Next.js)

1) ارفعي WhatsAppAlertButton.tsx إلى src/components/ (أنشئي المجلد إذا لم يوجد).
2) في صفحة الإعدادات الحالية، استوردي المكوّن:
   import WhatsAppAlertButton from "@/components/WhatsAppAlertButton";
3) ضعي <WhatsAppAlertButton /> في موضع قسم واتساب.
4) احفظي التغييرات في GitHub وانتظري نشر Vercel.

مهم: هذا مكوّن إضافي وليس بديلًا عن page.tsx. لا تستبدلي ملفات الصفحات الموجودة به.
يعمل من المتصفح ويفتح wa.me برسالة معدة مسبقًا. الإرسال النهائي يدوي داخل واتساب.
لا يحتاج Twilio، ولا ينشئ سجلات إرسال مؤكدة داخل النظام.
إذا كان مشروعك يستخدم app/ بدل src/app/، ضعي المكوّن في components/ وعدّلي مسار الاستيراد.
